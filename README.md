Shadow Veil is a top-down 2D stealth game that runs as plain static files — no build step, no network. Night shift at the Meridian Archive: slip past patrolling guards and their vision cones, use crates and shadow pools as cover, pocket all 3 clues, and reach the green exit unseen. Guards patrol waypoints, scan rooms, grow suspicious, chase when they spot you — and give you a chance to break line of sight and recover. Two levels, lives, a detection meter, synthesized WebAudio footsteps and alarms. Controls: WASD/arrows to move, Shift to sneak, click to walk there, M to mute, R to restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. `main.ts` hands the entry in (`MAKEFUN_OUTPUT_DIR=out node main.ts`).
